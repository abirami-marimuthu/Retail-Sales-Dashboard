# Retail Sales Performance Dashboard

##  Project Overview
This project analyzes retail sales data using Power BI to identify sales trends, product performance, profitability, and city-wise sales distribution.

##  Tools Used
- Power BI
- Excel

##  Dashboard Features
- KPI Cards
- Sales Trend Analysis
- Product Performance
- City-wise Sales Map
- Cross-filtering
- Date Slicer

## Key Insights
- High-performing cities contributed major revenue
- Certain categories generated higher profits
- Sales trends changed over time
- Interactive filtering improved analysis
